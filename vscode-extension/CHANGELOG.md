# Changelog

## 1.0.0

First release.

- Activity bar container with Health, Current File and Hotspots views.
- Blast Radius panel for files and declarations, themed with VS Code colors.
- Code health findings in the Problems panel, with a configurable minimum severity.
- CodeLens with reference counts and change risk above top-level types and functions.
- Find References (Graph) and Find Callers in the native references peek.
- Ask the Codebase: natural language search over the index.
- Health score in the status bar.
- Incremental indexing on startup and on save.
- MCP server registration for VS Code 1.101 and later, and Copy MCP Config for other clients.
- Open in Vesalius App through the `vesalius://open` link.
